## Editing This Wiki

This wiki is open for any GitHub user to edit. Please follow these guidelines:

- **Be helpful** -- Write for someone who will read this at 2am while debugging
- **Be concise** -- Short, actionable entries are better than essays
- **Use the templates** -- Each page has a format. Follow it for consistency
- **Cite your sources** -- If you found a fix somewhere, link to it
- **Don't delete others' entries** -- Add your own, improve existing ones

Spam and vandalism are automatically detected and reverted.
