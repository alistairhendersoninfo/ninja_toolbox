# LLM CLI Tools

Command-line interfaces for Large Language Models.

## Scripts

| Script | Description | Type |
|--------|-------------|------|
| Claude CLI | Anthropic's official Claude CLI | install |
| Gemini CLI | Google's Gemini AI CLI | install |
| OpenAI Codex | OpenAI's code generation CLI | install |

## Quick Start

```bash
ninjamenu
# Navigate to: Llm -> Cli -> Claude CLI
```

## Requirements

- Node.js 20.x (installed by nodejs.sh in postsetup-kali)
- API keys from respective providers

## Tags

`llm` `cli` `claude` `gemini` `openai` `codex`
