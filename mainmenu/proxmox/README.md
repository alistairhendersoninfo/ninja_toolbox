# Proxmox Tools

Tools for Proxmox VE hypervisor management.

## Scripts

| Script | Description | Type |
|--------|-------------|------|
| ProxMenux | Interactive Proxmox management menu | install |
| Proxmox Toolbox | Quick first-time PVE configuration | install |
| PVE Helper Scripts | 400+ community helper scripts | install |

## Quick Start

```bash
ninjamenu
# Navigate to: Proxmox -> ProxMenux
```
