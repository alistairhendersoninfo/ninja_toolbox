# Desktops

Desktop environments and display managers for Linux systems.

## Scripts

| Script | Description | Type |
|--------|-------------|------|
| KDE Plasma | Full-featured KDE Plasma desktop with Wayland support | install |
| Cinnamon | Traditional desktop environment forked from GNOME 3 | install |
| Hyprland | Dynamic tiling Wayland compositor with animations | install |
| SDDM | Simple Desktop Display Manager with Breeze theme | install |

## Quick Start

```bash
ninjamenu
# Navigate to: Desktops -> Desktop Environments -> pick an environment
# Or: Desktops -> Display Managers -> SDDM
```

## Included Software

### Desktop Environments

- **KDE Plasma** - Feature-rich desktop with Dolphin, Konsole, and Wayland support
- **Cinnamon** - Traditional GNOME 3 fork with Nemo file manager and LightDM
- **Hyprland** - Tiling Wayland compositor with Waybar, Wofi, and animations

### Display Managers

- **SDDM** - Lightweight display manager used by KDE, includes Breeze theme

- Root access for installation
- Debian-based system (Kali, Debian, Ubuntu)
- Hyprland may require newer repository versions (Debian Sid/Trixie or Ubuntu 24.04+)
