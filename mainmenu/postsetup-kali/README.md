# Kali Post-Setup

Post-installation configuration scripts for Kali Linux.

## Scripts

| Script | Description | Type |
|--------|-------------|------|
| Node.js | Install Node.js 20.x LTS | install |
| Fix ZSH | Fix ZSH undercover mode errors | config |
| Proxmox Tools | Install qemu-guest-agent for VMs | install |
| Catppuccin Themes | Install Mocha/Macchiato themes | install |
| XRDP with XFCE | Remote desktop access | install |

## Quick Start

```bash
ninjamenu
# Navigate to: PostsetupKali -> Node.js
```
