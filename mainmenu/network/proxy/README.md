# Proxy & DNS

Proxy servers and DNS services.

## Scripts

| Script | Description | Type |
|--------|-------------|------|
| Technitium DNS | Self-hosted DNS server with web management UI via Docker | install |
| Squid Proxy | Caching HTTP proxy server with access controls | install |

## Quick Start

```bash
ninjamenu
# Navigate to: Network -> Proxy & DNS -> Technitium DNS
```

## Requirements

- Root/sudo access
- Docker (for Technitium)
- Debian-based Linux (Kali, Debian, Ubuntu)
