# Git & GitHub Tools

Git and GitHub integration tools for SSH-based authentication and repository management.

## Scripts

| Script | Description | Type |
|--------|-------------|------|
| Git & GitHub Setup | Install git, gh CLI, create SSH key, authenticate | install |
| Test GitHub Connection | Verify SSH authentication works | config |
| Reset Git Credentials | Clear auth (keeps SSH keys unless 'destroy') | config |
| Push to GitHub Repo | Create repo and push any folder | config |

## Quick Start

```bash
ninjamenu
# Navigate to: Git -> Git & GitHub Setup
```
