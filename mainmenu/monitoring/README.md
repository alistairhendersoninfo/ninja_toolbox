## Quick Start

```bash
ninjamenu
# Navigate to: Monitoring -> pick individual tool or Install All
```

## Included Tools

### Process Monitors
- **htop** - Interactive process viewer with color display
- **atop** - Advanced system & process monitor
- **btop** - Modern, beautiful resource monitor

### I/O Monitors
- **iotop** - Monitor disk I/O by process
- **iftop** - Network bandwidth per connection
- **dstat** - Versatile resource statistics

### System Info
- **neofetch** - System info display
- **inxi** - Full system information
- **lshw** - Hardware lister
- **hwinfo** - Hardware information

### Disk Usage
- **ncdu** - NCurses disk usage analyzer
- **duf** - Disk usage/free utility

### Performance
- **sysstat** - System performance tools (sar, iostat)
- **nmon** - Performance monitor
- **glances** - All-in-one system monitor
