# Databases

Database servers and message brokers.

## Scripts

| Script | Description | Type |
|--------|-------------|------|
| PostgreSQL | General-purpose PostgreSQL relational database server | install |
| PostgreSQL (Security-Hardened) | Hardened PostgreSQL with SSL, strict pg_hba.conf, and Ory stack databases | install |
| RabbitMQ | Message broker with SSL/TLS and management console | install |

ninjamenu
