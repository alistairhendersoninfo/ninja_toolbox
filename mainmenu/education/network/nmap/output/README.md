# Nmap Output Scripts

Scan output formatting, export, and comparison techniques using Nmap.

## Scripts

| Script | Description | Root |
|--------|-------------|------|
| `diff-scans.sh` | Run two scans and compare differences with ndiff | No |
| `save-all-formats.sh` | Save scan results in XML, grepable, and normal formats | No |
| `xml-output.sh` | Save scan results as XML for tool parsing | No |

## Quick Start

```bash
ninjamenu
# Navigate to: Education -> Network -> Nmap -> Output
```

## Requirements

- `nmap` must be installed (install from **NinjaMenu > Network > nmap**)
- `ndiff` required for `diff-scans.sh` (included with nmap)

## Tags

`education` `nmap` `output` `xml` `reporting` `ndiff`
