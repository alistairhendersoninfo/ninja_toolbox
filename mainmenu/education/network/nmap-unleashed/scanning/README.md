# Nmap-Unleashed Scanning Scripts

Automated scanning workflows using nmap-unleashed profiles.

## Scripts

| Script | Description | Root |
|--------|-------------|------|
| `auto-scan.sh` | Run an automated nmap-unleashed scan with default profile | No |
| `custom-profile.sh` | Run a scan with user-selected nmap-unleashed options | No |
| `report-scan.sh` | Run a scan with HTML/XML report output | No |

## Quick Start

```bash
ninjamenu
# Navigate to: Education -> Network -> Nmap-Unleashed -> Scanning
```

## Requirements

- `nu` (nmap-unleashed) must be installed (install from **NinjaMenu > Network > nmap-tools-bundle**)
