# Nmap-Unleashed Reporting Scripts

Report generation and export scripts for nmap-unleashed scan results.

## Scripts

| Script | Description | Root |
|--------|-------------|------|
| `html-report.sh` | Generate a formatted HTML scan report | No |
| `xml-export.sh` | Export scan results as XML for further analysis | No |

## Quick Start

```bash
ninjamenu
# Navigate to: Education -> Network -> Nmap-Unleashed -> Reporting
```

## Requirements

- `nu` (nmap-unleashed) must be installed (install from **NinjaMenu > Network > nmap-tools-bundle**)

## Tags

`education` `nmap-unleashed` `reporting` `html` `xml` `export`
