# Network Education Scripts

Educational scripts organised by network tool. Each subfolder groups scripts for a specific tool.

## Tools

| Tool | Description | Binary Required |
|------|-------------|-----------------|
| [nmap](nmap/) | Network mapper — scanning, footprinting, vulnerability detection, evasion, output | `nmap` |
| [nmap-unleashed](nmap-unleashed/) | Enhanced nmap wrapper with automated scanning and reporting | `nu` |

## Quick Start

```bash
ninjamenu
# Navigate to: Education -> Network -> pick a tool -> pick a technique
```

## Requirements

- The parent tool must be installed first (e.g., install nmap from **Network > nmap**)
- Scripts check for the required binary and block execution if not found
