# Contact

## Report a Bug

Found something broken? [Open a bug report](https://github.com/alistairhendersoninfo/ninja_toolbox/issues/new?template=bug_report.md) on GitHub.

Include your OS, menu backend (gum/whiptail/textual), and any log output from `.docs/logs/`.

## Request a Feature

Have an idea for a new tool or improvement? [Open a feature request](https://github.com/alistairhendersoninfo/ninja_toolbox/issues/new?template=feature_request.md).

## Propose a New Script

Want to add a tool to the menu? [Submit a script proposal](https://github.com/alistairhendersoninfo/ninja_toolbox/issues/new?template=new_script.md).

## General Questions

For general questions and discussion, [start a discussion](https://github.com/alistairhendersoninfo/ninja_toolbox/discussions) or check the [Wiki FAQ](https://github.com/alistairhendersoninfo/ninja_toolbox/wiki/FAQ).
